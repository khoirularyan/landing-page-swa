# SWA Digital Solusindo — Digital Solution Partner

Official Landing Page untuk **PT SWA Digital Solusindo** dengan identitas modern *"Bisnis Berbeda. Solusi Tidak Harus Sama."*

## Fitur & Sections

- ✅ **Header & Sticky Navbar**: Glassmorphism blur saat scroll, link navigasi cepat, CTA Konsultasi, serta menu drawer responsif untuk mobile.
- ✅ **Hero Section**: Headline utama berani, overline badge, dan diagram alur ekosistem digital (*Ecosystem Timeline* dengan animasi pulsing nodes, traveling dot, dan chart aktivitas real-time).
- ✅ **Solution Finder (Interaktif)**: Pemilihan berbasis 5 tantangan bisnis utama (*Sales & POS*, *Business Process*, *Digital & E-Commerce*, *HR & Attendance*, *Custom Digital Solution*) dengan kartu preview dinamis.
- ✅ **Journey ("Cara Kami Bekerja")**: 5 tahapan alur kerja terstruktur (*Understand*, *Analyze*, *Recommend*, *Implement*, *Improve*).
- ✅ **Two Ways ("Dua Pendekatan")**: Perbandingan dua opsi solusi: *Ready Solution* (Richz ecosystem) dan *Custom Solution* (alur Business Process -> System -> Integration -> Dashboard).
- ✅ **Richz Showcase (Interaktif)**: Tab showcase untuk 4 produk (*RichzPOS*, *RichzStore*, *RichzFNB*, *RichzSPOT*) lengkap dengan simulasi UI antarmuka sistem (Kasir POS, Grid E-Commerce, Kitchen Display System, dan Attendance Graph).
- ✅ **Custom Digital Solution**: Penjelasan layanan kustomisasi alur bisnis, integrasi sistem, dan transformasi digital.
- ✅ **Industries (Interaktif)**: Pemilihan 6 sektor industri (*Retail*, *F&B*, *Healthcare*, *Education*, *Distribution*, *Corporate*) dengan rincian tantangan, solusi, dan teknologi.
- ✅ **Customer Stories**: Studi kasus dunia nyata (*Kopi Karsa Nusantara*, *PT Medika Jaya Distribusi*, *Aruna Living*) dengan format Tantangan, Solusi, dan Hasil.
- ✅ **Why SWA ("Mengapa SWA")**: Dark section berkelas dengan 4 pilar filosofi kerja.
- ✅ **Insights**: Artikel wawasan strategis transformasi digital.
- ✅ **Final CTA**: Call-to-action konsultasi langsung via email.
- ✅ **Footer**: Brand info, tautan navigasi, sosial media, dan informasi kontak lengkap.
- ✅ **SEO & Metadata**: OpenGraph, Twitter card, dan JSON-LD schema organisasi terintegrasi.
- ✅ **Animasi Halus & Responsif**: Animasi Scroll Reveal menggunakan `IntersectionObserver`, transisi CSS, dan layout mobile-first.

## Teknologi

- **Backend**: Node.js dengan Express.js
- **Frontend**: HTML5 Semantik, Tailwind CSS (Compiled), Vanilla JavaScript ES6+
- **Font**: Google Fonts (*Plus Jakarta Sans*, *Manrope*, *Space Mono*)
- **Icons**: Lucide Icons (SVG)
- **Source Files**: Komponen React asli tersimpan di folder `src/` untuk kemudahan pengembangan di masa depan.

## Struktur Project

```
├── public/
│   ├── css/

```

## Menjalankan Server

1. Install dependencies (jika belum):
```bash
npm install
```

2. Jalankan server development:
```bash
npm run dev
```

3. Atau jalankan server production:
```bash
npm start
```

4. Buka browser pada:
```
http://localhost:3001
```
