Cara Deploy Aplikasi Node.js ke AWS EC2 untuk Production

AP

Andi Pratama

DevOps Engineer

📅 15 Maret 2025 • ⏱️ 12 menit baca
#AWS #Node.js #Deployment #DevOps #Production

Deploy aplikasi Node.js ke production bisa menjadi tantangan tersendiri, terutama jika Anda baru pertama kali melakukannya. Dalam tutorial ini, saya akan memandu Anda langkah demi langkah untuk deploy aplikasi Node.js ke AWS EC2 dengan konfigurasi production-ready.

Tutorial ini cocok untuk Anda yang ingin memahami proses deployment dari awal hingga aplikasi berjalan dengan aman dan stabil di production.

📋 Apa yang Akan Kita Pelajari?

  • Setup EC2 instance dari AWS Console
  • Install Node.js dan dependencies yang diperlukan
  • Konfigurasi NGINX sebagai reverse proxy
  • Setup SSL certificate dengan Let's Encrypt (HTTPS)
  • Mengelola aplikasi dengan PM2
  • Best practices untuk production deployment
  • Setup monitoring dan logging

💡 Prerequisites: Tutorial ini mengasumsikan Anda sudah memiliki akun AWS dan aplikasi Node.js yang siap di-deploy. Anda juga perlu domain name jika ingin menggunakan SSL.

1. Setup EC2 Instance

Membuat EC2 Instance Baru

Login ke AWS Console dan buat EC2 instance baru dengan spesifikasi berikut:

  • AMI: Ubuntu Server 22.04 LTS
  • Instance Type: t2.micro (untuk testing) atau t3.small (untuk production)
  • Storage: 20 GB SSD minimum
  • Security Group: Allow port 22 (SSH), 80 (HTTP), 443 (HTTPS), dan port aplikasi Node.js Anda

⚠️ Penting: Simpan file .pem key pair Anda dengan aman! Anda akan membutuhkannya untuk SSH ke server.

Konfigurasi Security Group

Pastikan Security Group Anda mengizinkan traffic berikut:

Type            Protocol  Port Range  Source
SSH             TCP       22          0.0.0.0/0
HTTP            TCP       80          0.0.0.0/0
HTTPS           TCP       443         0.0.0.0/0
Custom TCP      TCP       3000        0.0.0.0/0 (untuk development)

Connect ke Server via SSH

Setelah instance running, connect via SSH:

# Ubah permission file .pem
chmod 400 your-key.pem

# Connect ke server
ssh -i "your-key.pem" ubuntu@your-ec2-public-ip

2. Install Node.js dan Dependencies

Update System Package

# Update package list
sudo apt update

# Upgrade installed packages
sudo apt upgrade -y

Install Node.js via NodeSource

Kita akan menggunakan NodeSource repository untuk mendapatkan versi Node.js terbaru:

# Install Node.js 20.x (LTS)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Verify installation
node --version
npm --version

Install Git

sudo apt install git -y

3. Clone dan Setup Aplikasi

Clone Repository

# Clone aplikasi dari repository
git clone https://github.com/your-username/your-app.git
cd your-app

# Install dependencies
npm install --production

Setup Environment Variables

Buat file .env untuk menyimpan environment variables:

# Buat file .env
nano .env

Isi dengan konfigurasi Anda:

NODE_ENV=production
PORT=3000
DATABASE_URL=your_database_url
JWT_SECRET=your_jwt_secret
API_KEY=your_api_key

🔒 Security Note: Jangan commit file .env ke Git! Pastikan .env ada di .gitignore Anda.

4. Setup PM2 untuk Process Management

PM2 adalah process manager untuk Node.js yang akan menjaga aplikasi Anda tetap running dan restart otomatis jika crash.

Install PM2 Globally

sudo npm install -g pm2

Start Aplikasi dengan PM2

# Start aplikasi
pm2 start app.js --name "my-app"

# Atau jika menggunakan npm script
pm2 start npm --name "my-app" -- start

# Lihat status aplikasi
pm2 status

# Lihat logs
pm2 logs

# Monitor real-time
pm2 monit

Setup PM2 Startup Script

Agar PM2 otomatis start saat server reboot:

# Generate startup script
pm2 startup systemd

# Save current PM2 process list
pm2 save

# Test dengan reboot server
sudo reboot

Konfigurasi PM2 Ecosystem File

Untuk konfigurasi lebih advanced, buat file ecosystem.config.js:

module.exports = {
  apps: [{
    name: 'my-app',
    script: './app.js',
    instances: 'max',
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'production',
      PORT: 3000
    },
    error_file: './logs/err.log',
    out_file: './logs/out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss Z',
    max_memory_restart: '500M'
  }]
}

Jalankan dengan:

pm2 start ecosystem.config.js

5. Setup NGINX sebagai Reverse Proxy

NGINX akan menerima request dari internet dan meneruskannya ke aplikasi Node.js Anda.

Install NGINX

sudo apt install nginx -y

# Start NGINX
sudo systemctl start nginx

# Enable auto-start on boot
sudo systemctl enable nginx

# Check status
sudo systemctl status nginx

Konfigurasi NGINX

Buat file konfigurasi untuk aplikasi Anda:

sudo nano /etc/nginx/sites-available/my-app

Isi dengan konfigurasi berikut:

server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }

    # Optional: Serve static files directly
    location /static {
        alias /home/ubuntu/your-app/public;
        expires 30d;
    }
}

Aktifkan Konfigurasi

# Create symbolic link
sudo ln -s /etc/nginx/sites-available/my-app /etc/nginx/sites-enabled/

# Test konfigurasi
sudo nginx -t

# Reload NGINX
sudo systemctl reload nginx

6. Setup SSL dengan Let's Encrypt

SSL certificate gratis dari Let's Encrypt untuk mengamankan aplikasi dengan HTTPS.

Install Certbot

sudo apt install certbot python3-certbot-nginx -y

Dapatkan SSL Certificate

# Generate certificate dan auto-configure NGINX
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# Ikuti prompt untuk email dan agreement

Certbot akan otomatis update konfigurasi NGINX Anda dan redirect HTTP ke HTTPS.

Test Auto-Renewal

# Test renewal process
sudo certbot renew --dry-run

Certificate akan otomatis diperpanjang sebelum expire.

7. Best Practices untuk Production

🔐 Security

  • Firewall: Setup UFW untuk membatasi akses port
  • SSH Key Only: Disable password authentication
  • Non-root User: Jangan run aplikasi sebagai root
  • Environment Variables: Simpan credentials dengan aman
  • Rate Limiting: Implementasi rate limiting di NGINX

Setup UFW Firewall

# Enable firewall
sudo ufw enable

# Allow SSH, HTTP, HTTPS
sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Check status
sudo ufw status

⚡ Performance

  • Cluster Mode: Gunakan PM2 cluster mode untuk multi-core CPU
  • Caching: Implementasi Redis untuk caching
  • CDN: Gunakan CloudFront untuk static assets
  • Compression: Enable gzip di NGINX

Enable Gzip di NGINX

Edit /etc/nginx/nginx.conf:

gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript application/json application/javascript application/xml+rss;

8. Monitoring dan Logging

PM2 Monitoring

# Real-time monitoring
pm2 monit

# View logs
pm2 logs

# View logs for specific app
pm2 logs my-app

# View error logs only
pm2 logs my-app --err

Setup Log Rotation

Install PM2 logrotate module:

pm2 install pm2-logrotate

# Configure rotation
pm2 set pm2-logrotate:max_size 10M
pm2 set pm2-logrotate:retain 7
pm2 set pm2-logrotate:compress true

NGINX Logs

# Access logs
sudo tail -f /var/log/nginx/access.log

# Error logs
sudo tail -f /var/log/nginx/error.log

System Monitoring

Install dan gunakan htop untuk monitoring resource:

sudo apt install htop -y
htop

9. Deployment Workflow

Update Aplikasi

Berikut workflow untuk update aplikasi di production:

# 1. SSH ke server
ssh -i "your-key.pem" ubuntu@your-server-ip

# 2. Navigate ke app directory
cd your-app

# 3. Pull latest changes
git pull origin main

# 4. Install new dependencies (if any)
npm install --production

# 5. Restart app dengan PM2
pm2 restart my-app

# 6. Check status
pm2 status
pm2 logs my-app --lines 50

Rollback Strategy

# List PM2 saved processes
pm2 list

# Rollback to previous version via Git
git log --oneline
git checkout 
npm install --production
pm2 restart my-app

💡 Pro Tip: Gunakan CI/CD pipeline (GitHub Actions, GitLab CI) untuk automasi deployment. Ini akan menghemat waktu dan mengurangi human error.

10. Troubleshooting Common Issues

Aplikasi tidak bisa diakses

  • Check PM2 status: pm2 status
  • Check NGINX status: sudo systemctl status nginx
  • Check security group AWS (port 80, 443 allowed?)
  • Check NGINX error logs: sudo tail -f /var/log/nginx/error.log

SSL Certificate Issues

# Renew manually
sudo certbot renew

# Check certificate status
sudo certbot certificates

Port Already in Use

# Find process using port
sudo lsof -i :3000

# Kill process
sudo kill -9
